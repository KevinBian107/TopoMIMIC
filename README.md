# Seeing the Boundaries: Topological Clustering of Common Behavioral Transitions

![Demo](figures/torus_dm_demo.gif)
> Demonstration of discrete Morse traversal (cycle) on a torus.

This code base is designed to develope an unsupervised behavior clustering algorithm by looking at the latent space of [Mimic-mjx](https://github.com/talmolab/Mimic-mjx).

- [View demo presentations](https://1drv.ms/p/c/98d7a8c1c4098906/EWaQUCtAdxhOnRaLUJEzJ4ABF2L1F52lpLsUqw0Z8AQzcA)
- [View SfN poster](https://drive.google.com/file/d/1tTwwww-OyBqC_tmbU0du2dtpfIY9_OI4/view)

## Environment Instantiation
We setup this repository similar to the [Mimic-mjx package](https://github.com/talmolab/track-mjx). All the `jax` dependency should be following the ones that is specified in `Mimic-mjx`. Besides the `Mimic-mjx` environment, please also download some of the TDA related packages using the following:

```bash
pip install -r requirements.txt
```

We alsp uses the DM graph repo implemented in [this repository](https://github.com/lucasjmagee/PCD-Graph-Recon-DM/tree/main), which requires ths following compilation steps:

```bash
git clone https://github.com/lucasjmagee/PCD-Graph-Recon-DM.git

cd dmpcd/code/persistence_swr
g++ DiMoSC.cpp -I./phat/include -std=c++11 -o DiMoSC

cd dmpcd/code/phat_morse_src
g++ ComputeGraphReconstruction.cpp -std=c++11 -o ComputeGraphReconstruction
```

Use the following to check if the compilation is successful:

```bash
ls -lh dmpcd/code/persistence_swr/spt_cpp
ls -lh dmpcd/code/phat_morse_src/a.out
```

## Data & Notebook Access
The data used for this analysis can be generated by the `Mimic-mjx` package, this study can be reproduced from using `Stack-mjx` and `Mimic-mjx`. We provide the exact rollout dataset that we used for this study in [this drive for labeling](https://drive.google.com/file/d/1sYFkKQGJ0qTJGm0fEigXRn4dKGzGv7qQ/view?usp=drive_link) and [this drive for clustering](https://drive.google.com/file/d/1exMwbJbJAqhJdKvT6ez9POY-bFGYbemN/view?usp=sharing). You can use gdown to download. The labeling dataset was trained with tighter KL bound for better visualization purposes and the clustering dataset was trained with looser KL bound for easier clustering purposes.

We provide 3 notebooks for different part of the analysis:
- [discrete-morse-compression](/notebooks/discrete_morse.ipynb) is the main topological data analysis notebook using discrete morse graph theory, as well as the entry point of most of teh analysis down in this project.
- [persistent-homology](/notebooks/persistent_homology.ipynb) is the alternative approach using persistent homology cocycles.
- [projection](/notebooks/projection.ipynb) uses traditional dimensionality reduction techniques to render the projection space with mujoco rendering.

## Annotation
We created this easy-to-use [annotation framework](https://github.com/ericleonardis/annotation-gui/) to annotate different animal behaviors using this [behavior lexicon](https://docs.google.com/document/d/19UC5Mu5mj_zmh2jDSHkML7WvMbdC4DbXrow3f1WBxC4/edit?usp=sharing). We have provided the [rendered videos here](https://drive.google.com/drive/folders/1tCw60UmBeP8hPDwPVnugsva0yIyO_mFU?usp=sharing). To retrieve all the videos, run the following:

```bash
python -m scripts.additional.render_for_label configs/additional/render_for_label.yaml
```

In addition, we can also identify the common transitions in the real data by running the following:

```bash
python -m scripts.additional.analyze_transitions
```

## Running the Codebase

### Method & Codebase Structure
Refer to the [documentation folder](/docs/) for more detailed information on the method and codebase structure:
- [our methods](/docs/methods.md)
- [codebase structure](/docs/codebase_structure.md)

### Hyperparameter Tuning
Find optimal Takens embedding (m, tau) and DM parameters (k_neighbors, pers_delta) first prior to clustering, this is a crtical parameter search for the unsupervised learning method to work:
```bash
python -m scripts.dmwkc.dm_hypertune configs/dmwkc/dm_hypertune.yaml
```

Usually, $k=3$ and $\delta = 1.0$ would be a good combination.

### Extract DM Graphs
Run discrete Morse extraction on all clips:
```bash
python -m scripts.dmwkc.dm_pipeline configs/dmwkc/dm_pipeline.yaml
```

### Run Benchmark Experiment
Run all clustering methods with integrated seeds and auto-generated labels.yaml:
```bash
python -m scripts.benchmark.experiment configs/benchmark/experiment.yaml
```

This runs all enabled methods (vanilla_kmeans, pca_kmeans, umap_kmeans, w2_kmeans, spectral, arhmm, slds).

### Analysis
Generate variance heatmaps, cross-method comparison, and seed stability analysis:
```bash
python -m scripts.benchmark.analysis.main configs/benchmark/analysis.yaml
```

## Rendering
To extract the clips with "filled space", representing only single behavior mode within it:
```bash
python -m scripts.additional.extract_filled_space configs/additional/extract_filled_space.yaml
```

To render cycles for visualization:
