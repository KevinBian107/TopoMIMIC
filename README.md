# Topological Clustering of Neuromechanical Agent's Naturalistic Behavior

***The value of the data itself is equivalence to the spatial organization. Hence, by understanding the spatial organziation, we will be understanding the data directly. If the shape of the data is the same, any transformation of it will just be linear in space.***

This code base is designed to be looking at such latent space of [Mimic-mjx](https://github.com/talmolab/Mimic-mjx) package via a topological perspective using optimized TDA pacakegs, hoping to find the `basis` of behaviors and controls.

## Environment Instantiation
We setup this repository similar to the `Mimic-mjx` package. For the current development version, use the following procedure:

```bash
git clone https://github.com/talmolab/Mimic-mjx.git
pip install --editable .[dev]
```

All the `jax` dependency should be following the ones that is specified in `Mimic-mjx`. In addition,ensure that you are using `pip install mujoco-mjx` instead of `mujoco`. Besides the `Mimic-mjx` environment, please also download some of the TDA related packages using the following:

```bash
pip install -r requirements.txt
```

Besides these traditional TDA packages, we uses DM graph implemented in [this repository](https://github.com/lucasjmagee/PCD-Graph-Recon-DM/tree/main), which requires ths following compilation steps:

```bash
git clone https://github.com/lucasjmagee/PCD-Graph-Recon-DM.git

cd dmpcd/code/persistence_swr
g++ DiMoSC.cpp -I./phat/include -std=c++11 -o DiMoSC

cd dmpcd/code/phat_morse_src
g++ ComputeGraphReconstruction.cpp -std=c++11 -o ComputeGraphReconstruction
```

Use thf ollowing to check if the compilation is successful:

```bash
ls -lh dmpcd/code/persistence_swr/spt_cpp
ls -lh dmpcd/code/phat_morse_src/a.out
```

## Data & Notebook Access
The data used for this analysis can be generated by the `Mimic-mjx` package, this study can be reproduced from using `Stack-mjx` and `Mimic-mjx`. We provide the exact rollout dataset that we used for this study in [this google drive](https://drive.google.com/drive/u/1/folders/12tFMNOYxKR3mIohNr4uPkhnap0ythq-s). You can use gdown to download the whole folder.

We provide 2 notebooks each with targetting an different part of the analysis:

- [discrete-morse-compression](/notebooks/discrete_morse.ipynb) is the main topological data analysis notebook using discrete morse graph theory, as well as the entry point of most of teh analysis down in this project.
- [persistent-homology](/notebooks/persistent_homology.ipynb) is the alternative approach using persistent homology cocycles.
- [projection](/notebooks/projection.ipynb) uses traditional dimensionality reduction techniques to render the projection space with mujoco rendering.

## Running the Codebase
To run our standard clustering scripts for batched processing on all clips for the sub-space topology, run

```python
python -m scripts.dm_latent_subspace
python -m scripts.dm_latent_subspace_auto_dunn
```

For hyper-tunning the sub-space topology, run

```python
python -m scripts.dm_latent_subspace_hypertune
```

For running the full-space topology, run

```python
python -m scripts.dm_latent_fullspace
```

For running our analysis code to get the same figure, run

```python
python -m scripts.analysis
```
