# Seeing the Boundaries: Topological Clustering of Behavioral Primitives and Transitions

This code base is designed to be looking at such latent space of [Mimic-mjx](https://github.com/talmolab/Mimic-mjx) package via a topological perspective using optimized TDA pacakegs, hoping to find the `basis` of behaviors and controls.

- [View demo presentations](https://1drv.ms/p/c/98d7a8c1c4098906/EWaQUCtAdxhOnRaLUJEzJ4ABF2L1F52lpLsUqw0Z8AQzcA)
- [View SfN poster](https://drive.google.com/file/d/1tTwwww-OyBqC_tmbU0du2dtpfIY9_OI4/view)

## Environment Instantiation
We setup this repository similar to the [Mimic-mjx package](https://github.com/talmolab/track-mjx). All the `jax` dependency should be following the ones that is specified in `Mimic-mjx`. Besides the `Mimic-mjx` environment, please also download some of the TDA related packages using the following:

```bash
pip install -r requirements.txt
```

We alsp uses the DM graph repo implemented in [this repository](https://github.com/lucasjmagee/PCD-Graph-Recon-DM/tree/main), which requires ths following compilation steps:

```bash
git clone https://github.com/lucasjmagee/PCD-Graph-Recon-DM.git

cd dmpcd/code/persistence_swr
g++ DiMoSC.cpp -I./phat/include -std=c++11 -o DiMoSC

cd dmpcd/code/phat_morse_src
g++ ComputeGraphReconstruction.cpp -std=c++11 -o ComputeGraphReconstruction
```

Use the following to check if the compilation is successful:

```bash
ls -lh dmpcd/code/persistence_swr/spt_cpp
ls -lh dmpcd/code/phat_morse_src/a.out
```

## Data & Notebook Access
The data used for this analysis can be generated by the `Mimic-mjx` package, this study can be reproduced from using `Stack-mjx` and `Mimic-mjx`. We provide the exact rollout dataset that we used for this study in [this google drive](https://drive.google.com/file/d/1sYFkKQGJ0qTJGm0fEigXRn4dKGzGv7qQ/view?usp=sharing). You can use gdown to download the whole folder. We provide 2 notebooks each with targetting an different part of the analysis:
- [discrete-morse-compression](/notebooks/discrete_morse.ipynb) is the main topological data analysis notebook using discrete morse graph theory, as well as the entry point of most of teh analysis down in this project.
- [persistent-homology](/notebooks/persistent_homology.ipynb) is the alternative approach using persistent homology cocycles.
- [projection](/notebooks/projection.ipynb) uses traditional dimensionality reduction techniques to render the projection space with mujoco rendering.

## Annotation
We created this easy-to-use [annotation framework](https://github.com/ericleonardis/annotation-gui/) to annotate different animal behaviors using this [behavior lexicon](https://docs.google.com/document/d/19UC5Mu5mj_zmh2jDSHkML7WvMbdC4DbXrow3f1WBxC4/edit?usp=sharing). We have provided the [rendered videos here](https://drive.google.com/drive/folders/1tCw60UmBeP8hPDwPVnugsva0yIyO_mFU?usp=sharing). To retrieve all the videos, run the following:

```bash
python -m scripts.render_for_label configs/render_for_label.yaml
```

## Running the Codebase
To run our standard clustering scripts for batched processing on all clips for the sub-space topology, run the following:

```bash
python -m scripts.dmwkc.dm_latent_subspace_auto_dunn
```

For hyper-tunning the sub-space topology, run the following:

```bash
python -m scripts.dmwkc.dm_latent_subspace_hypertune
```

For running our analysis code to get the same figure, run the following:

```bash
python -m scripts.dmwkc_experiment.analysis
```

To extract the clips with "filled space", representing only single behavior mode within it, run the following:

```bash
python -m scripts.dmwkc_experiment.extract_filled_space
```

When sampling at different scale, the clustering method picks up different granularity of "changes" occuring in the space, results in clusters at different frequency (i.e. target length of 30 frames capture turning motion whereas target length of 90 frames capture behaviors like rear left turn)

```bash
python -m scripts.dmwkc_experiment.sample_scale
```


## Running Benchmark
To run our benchmark comparison, which include clustering method like KMeans, DBSCAN and Spectral Clustering, and state space models like SLDS and AR-HMM, run the following:

```bash
python -m scripts.benchmark.benchmark_cluster
python -m scripts.benchmark.benchmark_kpms
```

And run the corresponding benchmark analysis to get our figure, run the following:

```bash
python -m scripts.benchmark.benchmark_analysis
```

## Segmentation on Novel Clips
To run segmentation on the 500 frame scale on novel clips, run the following:

```bash
python -m scripts.dmwkc_experiment.segmentation
```
