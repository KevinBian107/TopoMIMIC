# Seeing the Boundaries: Topological Clustering of Behavioral Primitives and Transitions

This code base is designed to be looking at such latent space of [Mimic-mjx](https://github.com/talmolab/Mimic-mjx) package via a topological perspective using optimized TDA pacakegs, hoping to find the `basis` of behaviors and controls.

## Environment Instantiation
We setup this repository similar to the [Mimic-mjx package](https://github.com/talmolab/track-mjx). All the `jax` dependency should be following the ones that is specified in `Mimic-mjx`. Besides the `Mimic-mjx` environment, please also download some of the TDA related packages using the following:

```bash
pip install -r requirements.txt
```

We alsp uses the DM graph repo implemented in [this repository](https://github.com/lucasjmagee/PCD-Graph-Recon-DM/tree/main), which requires ths following compilation steps:

```bash
git clone https://github.com/lucasjmagee/PCD-Graph-Recon-DM.git

cd dmpcd/code/persistence_swr
g++ DiMoSC.cpp -I./phat/include -std=c++11 -o DiMoSC

cd dmpcd/code/phat_morse_src
g++ ComputeGraphReconstruction.cpp -std=c++11 -o ComputeGraphReconstruction
```

Use the following to check if the compilation is successful:

```bash
ls -lh dmpcd/code/persistence_swr/spt_cpp
ls -lh dmpcd/code/phat_morse_src/a.out
```

## Data & Notebook Access
The data used for this analysis can be generated by the `Mimic-mjx` package, this study can be reproduced from using `Stack-mjx` and `Mimic-mjx`. We provide the exact rollout dataset that we used for this study in [this google drive](https://drive.google.com/file/d/1sYFkKQGJ0qTJGm0fEigXRn4dKGzGv7qQ/view?usp=sharing). You can use gdown to download the whole folder. We provide 2 notebooks each with targetting an different part of the analysis:
- [discrete-morse-compression](/notebooks/discrete_morse.ipynb) is the main topological data analysis notebook using discrete morse graph theory, as well as the entry point of most of teh analysis down in this project.
- [persistent-homology](/notebooks/persistent_homology.ipynb) is the alternative approach using persistent homology cocycles.
- [projection](/notebooks/projection.ipynb) uses traditional dimensionality reduction techniques to render the projection space with mujoco rendering.

## Running the Codebase

### Step 1: Hyperparameter Tuning
Find optimal Takens embedding (m, tau) and DM parameters (k_neighbors, pers_delta) first prior to clustering, this is a crtical parameter search for the unsupervised learning method to work:
```bash
python -m scripts.dmwkc.dm_hypertune configs/dmwkc/dm_hypertune.yaml
```

We should be looking for:
- Number of Cycles: Want few (1-3) so we get one dominant persistent cycle, not many redundant interpolations.
- Cycle Coverage: Want moderate (~40-50%) since we only need the recurrent core, not transient frames that add noise.
- Mean Cycle Length: Want long cycles (~70-90 frames) close to target_len to minimize resampling distortion.
- Edge/Cycle Ratio: Want higher ratio indicating surviving cycles are well-supported by persistent edges, not spurious.

### Step 2: Extract DM Graphs
Run discrete Morse extraction on all clips:
```bash
python -m scripts.dmwkc.dm_pipeline configs/dmwkc/dm_pipeline.yaml
```

### Step 3: Run Benchmark Experiment
Run all clustering methods with integrated seeds and auto-generated labels.yaml:
```bash
python -m scripts.benchmark.experiment configs/benchmark/experiment.yaml
```

This runs all enabled methods (vanilla_kmeans, pca_kmeans, umap_kmeans, w2_kmeans, spectral, arhmm, slds) with:
- **K-selection**: Fixed k or automatic Dunn Index-based selection
- **Multiple seeds** for stability analysis
- **Hungarian alignment**: Automatically aligns cluster IDs across seeds so labels.yaml applies to all
- **Dunn Index** evaluation in joint space (qpos)


### Step 4: Analysis
Generate variance heatmaps, cross-method comparison, and seed stability analysis:
```bash
python -m scripts.benchmark.analysis configs/benchmark/analysis.yaml
```

Analysis includes:
- **Variance heatmaps**: Per-cluster body part variance
- **Cross-method comparison**: Dunn Index across methods
- **Seed stability**: Dunn variance + alignment scores across seeds
- **MDS projections**: Cluster visualization with behavior labels

### Additional Experiment Scripts

Split clips into temporal windows before DM extraction for multi-scale analysis:
```bash
python -m scripts.experiment.temporal_windowing configs/experiment/temporal_windowing.yaml
```

Sweep over different sampling resolutions to capture behaviors at different frequencies (e.g., target length of 30 frames captures fast turning motion, 90 frames captures slower behaviors like rear left turn):
```bash
python -m scripts.experiment.resolution_sweep configs/experiment/resolution_sweep.yaml
```

## Segmentation on Novel Clips
