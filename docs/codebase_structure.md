# TopoVNL Codebase Structure

A comprehensive guide to understanding the organization of the TopoVNL project for topological analysis of behavioral latent spaces.

---

## Project Overview

TopoVNL (Topological Virtual Neuroscience Lab) analyzes deep reinforcement learning latent spaces through computational topology. The project uses discrete Morse theory and persistent homology to extract interpretable structure from behavioral manifolds generated by the Mimic-MJX package.

```
                        TopoVNL Project
┌─────────────────────────────────────────────────────────────────┐
│                                                                 │
│    ┌──────────────┐    ┌──────────────┐    ┌──────────────┐    │
│    │  Mimic-MJX   │───▶│   TopoVNL    │───▶│   Analysis   │    │
│    │   Rollouts   │    │   Pipeline   │    │   Results    │    │
│    └──────────────┘    └──────────────┘    └──────────────┘    │
│                                                                 │
│    Input Data          TDA Processing      Visualization &      │
│    (latents,qpos)     (DM,W2,Cluster)     Interpretation       │
│                                                                 │
└─────────────────────────────────────────────────────────────────┘

Figure 1: High-level data flow from Mimic-MJX simulation outputs through
topological analysis to behavioral clustering results.
```

The C++ components must be compiled before use:

1. **persistence_swr/spt_cpp** - Computes persistence of sparse weighted Rips filtration
2. **phat_morse_src/a.out** - Performs discrete Morse graph reconstruction

### Key Scripts

**dm_pipeline.py** - Entry point for discrete Morse extraction. Loads intention data, applies Takens embedding, runs DM reconstruction, extracts cycles, and saves results.

**experiment.py** - Unified benchmarking runner. Loads pre-computed DM cycles, builds distance matrices (W2 or feature-based), runs clustering methods, generates videos, and saves labeled results.

**analysis.py** - Post-experiment analysis. Generates variance heatmaps, MDS projections, and cross-seed comparisons.

### Configuration Hierarchy

**dm_pipeline.yaml** defines:
- `data.dm_key`: HDF5 key for intention data (typically "intention")
- `data.rodent_rollout_dir`: Path to rollout data
- `takens.m`: Embedding dimension (typically 3)
- `takens.tau`: Time delay (typically 6)
- `dm.pers_delta`: Persistence threshold
- `dm.k_neighbors`: kNN for density weights

**experiment.yaml** defines:
- `dm.results_dir`: Path to DM pipeline output
- `clustering.target_len`: Uniform sampling length
- `clustering.only_max`: Whether to keep only longest cycle
- `k_selection.n_clusters`: Number of clusters
- `methods`: List of enabled clustering methods
- `seeds`: Random seeds for reproducibility

## Method Registry

### Available Clustering Methods

| Method | Description | Distance Type |
|--------|-------------|---------------|
| `vanilla_kmeans` | Direct KMeans on flattened features | Euclidean |
| `pca_kmeans` | PCA reduction then KMeans | Euclidean |
| `tsne_kmeans` | t-SNE embedding then KMeans | Euclidean |
| `umap_kmeans` | UMAP embedding then KMeans | Euclidean |
| `w2_kmeans` | W2 distance matrix → MDS → KMeans | Wasserstein-2 |
| `spectral` | Spectral clustering with kNN affinity | Graph-based |
| `dbscan` | Density-based clustering | Euclidean |
| `arhmm` | Autoregressive HMM (requires keypoint-moseq) | State-space |
| `slds` | Switching Linear Dynamical System | State-space |

## Key Dataclasses

### Configuration Dataclasses

**PipelineConfig** (dm_pipeline.py):
- `output_dir`: Output directory path
- `data`: DataConfig with source paths
- `takens`: TakensConfig with $m$ and $\tau$
- `dm`: DMConfig with persistence parameters
- `rendering`: RenderingConfig for video output

**ExperimentConfig** (experiment.py):
- `output_dir`: Output directory path
- `rodent_rollout_dir`: Data source path
- `split`: Data split ("train", "test", "all")
- `clustering`: ClusteringConfig with window parameters
- `k_selection`: KSelectionConfig with cluster count
- `seeds`: List of random seeds
- `methods`: List of MethodEntry objects

**ClusteringResult** (methods.py):
- `labels`: Cluster assignment array
- `n_clusters`: Number of clusters found
- `method_name`: Name of clustering method
- `seed`: Random seed used
- `extra`: Additional method-specific data

## Quick Reference: Running the Pipeline

**Step 1: Run DM Extraction**
```bash
python scripts/dmwkc/dm_pipeline.py configs/dmwkc/dm_pipeline.yaml
```

**Step 2: Run Benchmark Experiments**
```bash
python scripts/benchmark/experiment.py configs/benchmark/experiment.yaml
```

**Step 3: Run Analysis**
```bash
python -m scripts.benchmark.analysis.main configs/benchmark/analysis.yaml
```
